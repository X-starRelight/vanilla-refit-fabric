# Vanilla Refit Fabric（原版精修）

Vanilla Refit Fabric（原版精修）是一个 Fabric Mod，在原版基础上做建筑形态扩展与细节打磨：新增竖半砖、竖楼梯、混合半砖三种建筑形态，并为台阶、楼梯、火把、灯笼、栅栏、墙、玻璃板、铁栏杆、铁砧等原版方块附带一批体验调整。所有新增形态由方块状态控制且默认关闭——中途加入不会改变存档中已放置的方块，卸载后世界中的方块退回原版外观，不会丢失。

## 基本信息

| 项 | 值 |
|---|---|
| 模组 id | `vanilla_refit_fabric` |
| 支持版本 | 26.2 Fabric |
| 运行环境 | 客户端与服务端均可 |
| 配置文件 | `config/vanilla_refit_fabric.json` |
| 构建 | Gradle（`./gradlew build`） |
| 许可 | MIT |

## 特性

- **竖放台阶与楼梯**：台阶和楼梯均可竖放，放置逻辑由按键切换，台阶与楼梯各自记忆
- **混合半砖**：同一格内叠放两种材质的半砖，潜行只拆一半，不潜行整体拆除
- **贴台阶附件**：火把、灯笼可贴合下台阶，灯笼还能挂在上台阶下方；栅栏与墙整体下移半格并正常连接
- **玻璃幕墙**：玻璃板与铁栏杆拆成 12 个部件，大面积铺开时自动隐藏中间竖直面片
- **不新增方块 id**：所有改动发生在原版方块上，卸载不丢方块，中途加入不变形已放置方块
- **其它原版调整**：玻璃类可镐/斧加速、栅栏间拴绳悬链线、铁砧不再逐渐损坏、爬行与坐下按键
- **机械动力飞跃版兼容**：对称之杖可正确翻转竖半砖、竖楼梯、组合半砖

## 效果速览

```text
按 V 切换放置逻辑（台阶与楼梯各自记忆，随存档保存）

默认：点击方块面靠外区域 → 竖放；点击中央区域 → 平放
紧贴：按点击的那个面 → 决定竖放朝向
原版：保留原版放置逻辑（台阶的混合半砖仍可用）
```

## 快速上手

### 环境要求

| 项 | 版本 |
|---|---|
| Minecraft | 26.2 Fabric |
| 运行环境 | 客户端与服务端均可 |

### 构建

```bash
./gradlew build       # 打包，产物在 build/libs
./gradlew runData     # 重新生成方块状态与模型
./gradlew runClient   # 启动开发环境客户端
```

### 配置

配置文件为 `config/vanilla_refit_fabric.json`，默认开启：

| 配置项 | 说明 |
|---|---|
| `allowTorchLanternOnSlab` | 火把/灯笼在下台阶上的贴合 |
| `allowLanternUnderTopSlab` | 灯笼悬挂在上台阶下 |
| `slabCenterSquareRatio` | 「默认」放置逻辑中中央正方形区域的大小 |
| `allowModdedSlabs` / `allowModdedStairs` | 其它模组的台阶 / 楼梯是否也能竖放（默认开启） |
| `blocklist` | 方块名单，决定哪些方块允许加竖形态（`+*` / `-*` / `+minecraft:oak_slab` / `+somemod:*` / `+#minecraft:wooden_slabs`）。只影响放置行为，不减少已注册的方块状态 |

### 游戏内验证

按 `V` 切换放置逻辑后，手持台阶/楼梯时显示分割辅助线（台阶为对角线、楼梯为十字线，只在完整面上绘制）；在方块面靠外区域点击得到竖形态，在中央区域点击得到平放形态。

## 台阶与楼梯

- 按 `V`（可在按键设置里改）切换放置逻辑，台阶与楼梯各自记忆，并随存档保存：
  - **默认**：点击方块面靠外区域竖放，点击中央区域平放；手持时显示分割辅助线（台阶为对角线、楼梯为十字线，只在完整面上绘制）。中央正方形区域的大小由 `slabCenterSquareRatio` 控制。
  - **紧贴**：按点击的那个面决定竖放朝向。
  - **原版**：保留原版放置逻辑（台阶的混合半砖仍然可用）。
- **混合半砖**：同一格内叠放两种材质的半砖；潜行时只拆掉其中一半，不潜行则整体拆除。
- 其它模组的台阶与楼梯默认也生效（竖形态模型由客户端按本模组模板运行时生成），可用配置整体关闭，或用方块名单逐个排除。

## 火把、灯笼、栅栏与墙

- 火把、灵魂火把、红石火把、灯笼、灵魂灯笼可放在下台阶上，模型、碰撞箱与粒子一起下移半格贴合台阶表面；灯笼也可挂在上台阶下方。
- 下台阶上的栅栏与墙整体下移半格，并与周围的栅栏/墙正常连接；墙在方块上方的满高判定已适配。
- 判定基于原版方块与标签，其它模组按原版方式实现的红石火把、灯笼等同样适用。

## 玻璃板与铁栏杆

- 玻璃板与铁栏杆拆成 12 个部件（东西南北各分上下两半，加上四个角的水平面片），大面积铺开时中间的竖直面片自动隐藏，拼出整块玻璃幕墙效果。
- 连接规则在原版基础上扩展（上下两半 + 四个角的面片），任意摆放顺序下结果一致。

## 其它原版改动

- 玻璃、玻璃板等玻璃类方块可用镐或斧加速挖掘。
- 拴绳可在两个栅栏之间拉出微微下垂的悬链线；点击栅栏上的绳结即可解开并返还拴绳，拆除栅栏同样解除连接。
- 铁砧：使用时不再逐渐损坏（只保留跌落受损）；用材料修复物品不再累积修复惩罚，修复比例由 25% 提高到 90%。
- 新增两个按键：爬行（默认 `Ctrl` 按住）与坐下（默认 `Z` 切换），均可在按键设置里更改。

## 兼容范围

- **原版方块**：完整适配。
- **楼梯、台阶**：其它模组的默认也生效（模型在客户端运行时按模板生成），可用 `allowModdedSlabs` / `allowModdedStairs` 整体关掉，或用 `blocklist` 逐个排除。
- **墙、栅栏**：只要继承原版类，均适用「贴台阶」的位移与跨台阶连接。
- **玻璃板、铁栏杆**：目前只适配原版的（其它模组的贴图命名不保证，暂不适配）。
- **火把、灯笼**：按标签判定（`vanilla_refit_fabric:on_slab_torch` / `vanilla_refit_fabric:on_slab_lantern`），基于原版类构造的加进对应标签即可生效。

本模组不给方块加新 id，所有改动都发生在原版方块上：卸载后世界里的方块不会消失，只会退回原版的样子；中途加入模组也不会改变已放好的方块。
